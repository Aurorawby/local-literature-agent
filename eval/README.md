# 评测：检索层 A/B 实验

## 这个目录是什么

一个可复现的检索质量评测，回答一个问题：

> **"换学术数据源 + 生成学术检索式 + 加相关性硬约束" 这套设计，真的比"直接拿主题去搜"更好吗？**

不是拍脑袋讲故事，而是同一批主题、同一批数据源下的对照实验。

## 怎么跑

```bash
.venv\Scripts\python.exe eval/run_eval.py                    # 10 个主题，完整评测
.venv\Scripts\python.exe eval/run_eval.py --topics llm_finance   # 只跑一个主题
.venv\Scripts\python.exe eval/run_eval.py --repeat 2 --out v2    # 每个主题重复 2 次取均值
```

输出：`results.json`（原始数据）、`RESULTS.md`（可直接引用的结果表）。

## 四种条件

| 条件 | 做法 | 对应产品决策 |
|---|---|---|
| **B0 naive** | 直接用中文主题当检索式，不做规划、不做约束 | 原版网页搜索的"学术版"对照 |
| **B1 检索式** | 模型生成英文学术检索式 + 多源检索（Crossref/DOAJ/arXiv）+ 去重打分，**不加约束** | 只做了"检索式规划"这一步 |
| **B2 hard（v1）** | B1 + 核心概念/应用领域**硬淘汰**（缺失即丢弃） | v1 线上逻辑 |
| **B3 soft（v2）** | B1 + **同义词扩展 + 软惩罚**（缺失只扣分，不丢弃） | v2 线上逻辑（当前默认） |

## 指标与标注口径

- **Precision@10**：前 10 篇里同时命中「核心概念」和「应用领域」的论文比例；
- **Core@10 / Domain@10**：只命中核心概念 / 只命中领域的比例，用来定位是哪一环失效；
- 标注方式是**关键词代理标注**：每个主题人工定义 `core_terms` 与 `domain_terms`，
  标题或摘要同时命中才算 on-topic（见 `topics.json`）。

> 这是代理指标，不是人工逐篇标注。绝对值不能和其他系统比，只能做**同条件对比**——
> 而"同条件对比"正是这个实验要回答的问题。

## 结果与解读（要点）

**v1（单次运行）**：B0 6.0% → B1 60.0% → B2 hard 66.0%
**v2（重复 2 次）**：B0 6.0% → B1 57.5% → B2 hard 64.5% → B3 soft 62.0%

| 结论 | 说明 |
|---|---|
| B0→B1 稳健 | 数量级差异，10 个主题里 9 个提升——这是"换学术源 + 检索式规划"的收益 |
| B1→B2 不显著 | 重复运行波动 ±11~14pp，+6pp 落在噪声里 |
| **B2→B3 也没提升** | v2（同义词 + 软惩罚）62.0% vs hard 64.5%，差在噪声内 |
| **评测有构念效度问题** | on-topic 判定用 `core/domain` 关键词，硬约束也用同一套词——**指标天然偏向硬约束，看不见"同义词误杀"** |

→ 所以 v2 上线**不是**因为 precision 提升，而是为了消除"硬淘汰误杀同义表达"的**结构性风险**；
它的收益需要**人工标注（100 篇）**才能验证，这一条写进下一步，不在作品集里宣称。

详细分析见 [`RESULTS.md`](RESULTS.md) 的"v2 迭代结果"一节。

## 模型对比（3B vs 7B）

`compare_models.py` 用同一批论文、同一套提示词，比"结构化抽取"的可靠性：

| 模型 | 平均耗时/篇 | 有效字段率 |
|---|---|---|
| qwen2.5:3b | 12.6s | **80%** |
| qwen2.5:7b | 35.7s | **100%** |

详细结果（含每篇的原始抽取 JSON，可人工核对）见 [`MODEL_COMPARISON.md`](MODEL_COMPARISON.md)。

```bash
.venv\Scripts\python.exe eval/compare_models.py --models qwen2.5:3b,qwen2.5:7b
```

## 局限（写清楚，别藏着）

1. 关键词标注会漏掉"用别的说法表达同一概念"的论文，也会误判个别标题党；
2. 主题只有 10 个，覆盖金融、能源、医疗、教育、政策、半导体，但样本仍小；
3. 只评测**检索层**；精读/综述质量用引用核验 + 人工抽查，不在这个实验里；
4. 单次运行噪声大，绝对值不可与其它系统比较；
5. 某些主题（中文政策类）英文文献本身稀少，B2 偏低是**真实的检索边界**，不应掩盖。

# 中文文献检索：一个可复现的小型基准（2026-11）

> 这不是“排行榜”，也不是“SOTA 声明”。它是一个**可复跑、带人工金标准、明确写局限**的评测集，
> 用来回答一个具体问题：**同一批中文研究主题，不同检索策略在前 10 篇里到底命中多少相关文献？**

---

## 1. 这个基准包含什么

| 项目 | 内容 |
|---|---|
| 主题 | 10 个中文研究主题（AI/金融、ESG、供应链、电池、医学影像、教育、数据要素、碳中和、芯片等） |
| 候选池 | 201 篇去重论文（B1/B3 top10 全量 + B0 前 4 / 每主题） |
| 人工标注 | **201 篇逐篇盲标**（1=不相关，2=部分相关，3=高度相关；标注时隐藏系统判定） |
| 条件 | B0 naive / B1 检索式 / B2 hard（规则）/ B3 soft（v2 线上） |
| 主指标 | 人工宽口径 P@10（label≥2）；严口径 P@10（label=3） |
| 统计 | 主题级 cluster bootstrap 95% CI；B1 vs B3 配对置换；MDE |
| 数据 | `human_eval_pool.json`、`lit_labels.json`、`human_eval_results.json`、`human_eval_stats.json` |
| 脚本 | `human_eval_stats.py`（只读数据、输出统计） |

---

## 2. 基线结果（不要脱离样本量读）

| 指标 | B1 检索式 | B3 soft（线上） |
|---|---|---|
| 人工宽口径 P@10（95% CI） | **84.0%（74–93）** | **84.0%（66–97）** |
| 人工严口径 P@10（95% CI） | 50.0%（36–63） | 61.0%（42–78） |
| 与规则代理标注的一致性 | κ=0.229（0.156–0.308） | 同左（同一批标注） |
| 与 7B 模型打分的一致性 | κ=0.152（0.064–0.237） | 同左 |

**B1 vs B3：** 宽口径差值 0pp（配对置换 p=1.00）；严口径 +11pp（p=0.125）——**不显著**；
10 个主题的 80% power MDE 约 16–27pp，所以 5–10pp 的差异测不出来。

**B0：** 只标了每主题前 4 篇（P@4）：人工宽口径 67.5%，规则 2.5%；**不能与 P@10 直接比较**。

## 3. 怎么复跑

```bash
# 只读数据，不调用模型
.venv\Scripts\python.exe eval/human_eval_stats.py
# 重新生成原始分析（LLM 分数有缓存；--no-llm 可跳过模型）
.venv\Scripts\python.exe eval/human_eval.py --no-llm
```

输出：`eval/human_eval_stats.json`；人工整理版报告见 [`HUMAN_EVAL.md`](HUMAN_EVAL.md)、
统计与实验设计见 [`AB_EXPERIMENT.md`](AB_EXPERIMENT.md)。

## 4. 为什么把它叫“基准”，而不是“我跑了一次评测”

- **有金标准**：201 篇人工逐篇标注，不是关键词代理；
- **有对照**：B0/B1/B2/B3 同主题、同数据源；
- **有统计**：主题级 CI、配对检验、MDE，不把噪声当提升；
- **有负面结果**：B3 不显著、7B 裁判不行、护栏会误伤——都保留；
- **可复跑**：数据 + 脚本 + 版本在仓库，任何人可以复现。

---

## 5. 边界与已知不足（必须一起读）

- 10 个主题、201 篇，样本小；只能检测约 16–27pp 的差异；
- **单人盲标**（作者本人），没有人类-人类 κ；标注者知道研究假设；
- B0 只标前 4 篇，不能与 P@10 直接比较；
- 主题既用于选策略又用于评估，没有真正的 holdout 主题；
- 检索源为 Crossref/DOAJ/arXiv/OpenAlex，不覆盖知网全文；
- 这是**离线评测**，不是线上 A/B；不能回答“用户会不会用/会不会留存”。

> 如果你要引用这个基准：请同时引用上面的边界；它适合做“策略对比 + 代理偏差分析”，不适合宣称“SOTA”。
